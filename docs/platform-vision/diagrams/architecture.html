数据智能平台（DIP）· 总体架构

v1.1 ｜ 实线 = Phase 1 已实现范围　·　虚线 = 后续阶段 / 可选　·　旧内核本期冻结，新平台只走 HTTP 契约

Phase 1：三个单元 + 一个库

  • • portal-web 前端（对话首屏 / 血缘 / 口径 / 报告）
  • • portal-api FastAPI（身份 / 会话 / Agent / 审计）
  • • lineage-api 旧内核（复用、不动）
  • • PostgreSQL 唯一数据库 —— 不上 Redis / Neo4j / 调度适配器

唯一耦合面 = HTTP 契约

  • • 新平台只经 integrations/lineage-client 调内核，不 import 内部模块
  • • contracts/openapi.yaml（16 端点）只追加字段，破坏性变更升 /v2
  • • 双仓库各自独立发布；Phase 5 之后才考虑抽包做进程内调用

产品主线：Evidence-first

  • • 对话是入口，血缘与口径是事实基础，凭证是可信机制
  • • 统一结果模型：value / confidence / status / evidence / source / version
  • • 没有凭证的回答不发布；写操作必须「生成 → 审核 → 执行」
