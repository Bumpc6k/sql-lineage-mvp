该表的指标口径：
  - 产量（条） = (打码量 + 跳码量 - 重码量) * 250   [聚合]
  - 产量 = 打码量 + 跳码量 - 重码量   [聚合]
  - 重码量合计 = SUM(重码量)   [聚合]
  - 打码量（条） = 打码量 * 250   [聚合]
  - 打码量合计 = SUM(打码量)   [聚合]
  - 打码占比 = CASE WHEN 打码量 + 跳码量 - 重码量 > 0 THEN ROUND(打码量 / (打码量 + 跳码量 - 重码量), 6) ELSE 0 END   [条件分支]
  - 跳码量合计 = SUM(跳码量)   [聚合]
